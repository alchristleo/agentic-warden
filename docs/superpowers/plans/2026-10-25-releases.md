# Releases plan

Spec: `docs/superpowers/specs/2026-10-25-releases-design.md`. Base: `612c69d`.

## Global constraints

- Never run plain `go mod tidy` (bumps go); use `GOTOOLCHAIN=local go mod tidy -e` only if needed.
- New module path: `github.com/alchristleo/agentic-warden`. Version var:
  `github.com/alchristleo/agentic-warden/internal/version.Version`.
- Archive: `agentic-warden_<version>_<os>_<arch>.tar.gz`, top level `aw aw-policy aw-sync awd LICENSE`;
  `checksums.txt` = `sha256sum` output (`<hex>  <file>`), one line per archive.
- Targets: linux/amd64, linux/arm64, darwin/amd64, darwin/arm64. No Windows.
- Release build: `CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -X <version var>=<v>"`, never `-tags awtest`.
- install.sh: POSIX sh, never calls sudo, writes nothing to `AW_BIN_DIR` on any failure.
  Env: `AW_VERSION` (default latest), `AW_BIN_DIR` (default `$HOME/.local/bin`),
  `AW_BASE_URL` (default `https://github.com/alchristleo/agentic-warden/releases`).
  URLs: latest → `<base>/latest/download/<file>`; pinned → `<base>/download/<version>/<file>`.
- No network publishing, no tag pushes. shellcheck is not installed locally; AC6's shellcheck runs on CI.

unstamped prints `dev`. Existing build-info e2e must still pass (only add a line).

### T3 Release build script — agent: sdd-implementer — depends-on: T2
Files: `scripts/release-build.sh <version> <outdir>`, `scripts/test-release-build.sh`.

OS/arch per binary; `sha256sum -c checksums.txt` passes in outdir; extracted linux/amd64
`aw-policy build-info` reports overrides off and `version v0.0.0-test`; refuses a version not matching `^v[0-9]`.

### T4 install.sh — agent: sdd-implementer — depends-on: T3
Files: `install.sh` (repo root), `scripts/test-install.sh <dist>`.
`test-install.sh` serves `<dist>` + `install.sh` with `python3 -m http.server` on 127.0.0.1 in a
`download/<version>/` and `latest/download/` layout, temp HOME, runs install.sh under `dash`.
Tests: AC4 happy path default dir + custom `AW_BIN_DIR` + pinned `AW_VERSION`, `aw version` prints the
dist version; AC5 tampered archive, missing checksum line, unsupported uname (PATH shim), 404 → each
non-zero with a clear message and `AW_BIN_DIR` listing byte-identical before/after; PATH hint printed
when dir not on PATH.

### T5 release.yml workflow — agent: sdd-implementer — depends-on: T3, T4 — parallel group A

All third-party actions pinned by full SHA (with a `# vX` comment). No `pull_request_target`.
Tests: `python3 -c` YAML parse; AC8 via panel-security; AC7 on PR CI.
